About Lumen

Lumen is a small, dynamically-typed scripting language implemented from scratch in Go. It walks the canonical compiler-construction pipeline — source → tokens → AST → values — and serves as a hands-on demonstration of recursive descent parsing, lexical scoping, and tree-walk interpretation.

01

Lexer scanner

Single-pass character scanner producing a stream of Token{Type, Literal, Line} values. Handles identifiers, numeric & string literals, two-character operators, and skips whitespace + comments.

02

Parser recursive descent · Pratt

A Pratt-style top-down parser with prefix and infix functions per token type. Builds typed AST nodes — LetStatement, FunctionLiteral, IfExpression, CallExpression — with full operator precedence.

03

Evaluator tree-walk

Recursive tree-walking interpreter. First-class functions and closures via captured Environment pointers. Built-ins: print, len, first, rest, push.
